临床转化医学垂直大模型 —— 不做通用医疗问答，只做申报与决策链路上的硬活

我们在做什么

通用医疗大模型在细分语域上知识稀薄且易产生幻觉——根因不在对齐不足， 而在基座语言模型没有这套语域的 token 分布。
我们的做法是：先把领域事实结构化，再谈模型；能力进权重，出处进检索，数据进工具调用。

目前在研两个垂直模型，共用同一套方法论与合规口径，覆盖「药物怎么申报」与「药物能做到多少疗效」 两条临床转化医学上最吃专业知识的链路。

共用方法论

两个模型共用同一套工程原则，这是复泽智药相对通用模型团队的真正差异。

四条原则，每条都对应一个在医药场景里被反复踩中的坑
原则为什么这么做
先 CPT 后 SFT 监管话术、终点设计、CMC 工艺描述是独立语域，基座缺这套 token 分布； 几千条指令样本改不动模型对它的先验
分层分离 能力进权重、事实进检索、数据库进工具调用。法规与疗效数据每月在变， 写进权重等于固化一个会过期且无法溯源的版本
复现式硬评测 留出真实试验，考入排标准、终点设计与疗效数字的复现，按条目算召回与精确率， 不做主观打分、不做人工偏好评测
语料全程合规 公有领域与 CC0 / CC-BY；排除 CC-BY-SA、全部 NC 与 ND； 不含任何商业模型蒸馏数据

数据底座

公开证据可量化、可复现；私有数据解决公开数据解决不了的问题。

以 Onco Efficacy LLM 的实测为例：对 10 个实体瘤与血液瘤检索「已完成的 II/III 期干预性试验」， 共 9,822 项，其中 4,330 项（44%）已张贴可直接解析的结构化结果。 这决定了公开层能撑起万条量级的试验级疗效记录，也暴露了公开层的边界—— 剩余约 56% 要靠文献与年会摘要抽取补齐。

私有数据层

公开层之外叠加四类私有数据。其中卫健委私有数据库与申办方未公开数据是关键增量—— 阳性结果更易发表，只用公开文献会系统性高估疗效。

  • 卫健委私有数据库——用于模型训练的国家级临床数据资产
  • 院内真实世界队列——疗效随访、影像评估、分子分型
  • 申办方未公开试验数据——含阴性结果，用于纠正发表偏倚
  • 专家标注集——抽取校验金标准与疗效可信度分级
数据合规前置。卫健委私有数据库与院内队列的使用，以数据使用协议、伦理审批与 去标识化处理为前提；相关授权文件在尽调时单独提供，不在本页列示。

F-Med 特点

不是从零造轮子，而是把 DeepSeek 已验证的组件按临床数据的性质重新排布。

F-Med 是把 DeepSeek 已验证的 MLA、细粒度 + 共享专家 MoE、MTP、GRPO，按临床数据的性质重新排布的垂直模型。

四个组件各自对应临床数据的一项具体性质；左为组件，右为「为什么临床数据需要它」
组件做了什么临床数据为什么需要它
MLA
潜向量注意力		把 KV cache 压成低秩潜向量，长上下文的显存瓶颈被解开临床试验方案书、CSR、整册年会摘要都极长——要能一次读完，而不是分段喂
MoE
细粒度 + 共享专家		细粒度专家按瘤种、终点类型、法规辖区切分；共享专家承载跨瘤种通用的临床统计与话术临床语域天然分区，但基础临床统计是所有分区共用的，不该让每个专家重学一遍
MTP
多 token 预测		多 token 训练目标，并提升结构化抽取吞吐疗效字段强耦合且成对出现：ORR 的分子分母、HR 与其置信区间，逐 token 预测容易拆散
GRPO
组相对策略优化		按试验分组算组内相对优势，无需人工偏好标注即可做强化学习疗效预测的奖励客观可验证（ORR 误差、HR 方向对错），且「同一试验多个臂」天然成组

现状与边界

写在正面而不是脚注里：

  • 模型权重尚未训练。两个项目当前交付的是语料资产、结构化事实库与评测基准。
  • 推理端点为口令内测，未对外开放。
  • 公开临床数据仅汇总级，个体患者疗效预测不在能力范围内。
  • 年会摘要与付费墙文献的召回率是整体性能上限，而非模型容量。
